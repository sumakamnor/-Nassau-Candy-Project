# 🍬 Nassau Candy - Supply Chain Dashboard

🚀 **LIVE DEMO:** https://kdn2wnzkm3qxtpnz6qqqsf.streamlit.app

## Project Overview
Analyzed 10,194 candy distribution orders to identify shipping bottlenecks and delivery performance.

## Key Insights
- Factory to Customer Analysis
- Region-wise shipping efficiency (Interior, Atlantic, Gulf, Pacific)
- Ship Mode performance (Standard, First Class, Second Class, Same Day)
- Delivery delay detection

## Tech Stack
- Python
- Streamlit
- Pandas
- Data Visualization

## Dataset
Nassau Candy Distributor.csv - 10,194 rows
